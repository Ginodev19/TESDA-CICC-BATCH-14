In Java, we use import statements to give our program access to pre-written code packages that are built into the Java language.
By default, Java only loads a very small, basic set of tools (like System.out.println or String). If you want to use more advanced features—like a Scanner for user input, an ArrayList for dynamic lists, or a Random generator—you have to tell Java where to find them.

User Input 

String x;
Scanner s =new Scanner(System.in);

x=s.nextline():

The reason it works even though the variables have different names (x and s) is that they are doing two completely different jobs. Java does not require them to have matching names because they don't depend on each other's identities.
Think of it like a real-world scenario:
• x is an empty box (a storage space) meant to hold text.
• s is a shovel (a tool) meant to grab data from the keyboard.
A box and a shovel are different things, have different names, and work independently. You only bring them together when you use the shovel to dump data into the box.
